### What I do

- **Backend, APIs & payments:** third-party API integration, Stripe billing with webhooks you can trust, data models that stay consistent when things fail halfway
- **AI in real products:** model calls with validation, cost control and the right model for the job (not always the newest one)
- **LINE bots & mini apps:** Messaging API, LIFF, rich menus, AI-powered chat flows
- **VFX pipeline & OpenUSD:** Houdini and Maya tooling, batch processing, asset workflows, Python architecture that survives production
- **AI imagery with art direction:** a consistent look across a whole series, not one lucky render
